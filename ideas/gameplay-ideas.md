# Gameplay Ideas

## Jump Mechanic Rework

**Current:** (unknown/basic)

**Proposed:**
- Activate jump by either:
  - Pressing a dedicated jump button, OR
  - Double-tapping any direction key (WASD) in quick succession
- Once airborne, use direction keys to navigate/steer the jump
- Feels more intentional and gives aerial control

---

## Debug Menu / Cheat Codes

**Access:** Click the tiny dot at bottom left of screen

**Password System:**
- Prompts for password input
- `logs` → Opens regular console view (copy/minimize)
- `dragon` → Grants dragon power-up
- `leaf` → Grants leaf power-up
- `wind` → Grants wind power-up

## Title Screen Sequence

**Opening:**
1. Samurai Bob's face appears
2. Music: "Oh My, He's a Crazy Samurai" style song
3. Text animation sequence:
   - "SAM" appears
   - "ER" appears
   - "I" appears
   - "BOB" appears
4. Player presses start
5. Bob's face shows
6. Transitions to main menu
